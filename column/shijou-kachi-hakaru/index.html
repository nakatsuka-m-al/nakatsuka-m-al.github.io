自分の市場価値を測る具体的な方法

最終更新 2026-08-28

「自分の市場価値がどのくらいか分からない」——多くの人が抱えるこの不明確さは、キャリアの判断を難しくします。転職すべきか、いまの待遇は妥当か、この先どんな選択肢があるのか。すべての判断の土台に、自分の現在地の把握があります。そして市場価値は、想像するものではなく、**実際に測れるもの**です。しかも、その多くは無料で、転職する意思がなくても実行できます。この記事では、市場価値を測る5つの具体的な方法と、それぞれの精度と限界、そして結果の正しい読み方を解説します。

目次

  1. 測定の前に：何を測るのかを整理する
  2. 方法1〜2：求人情報から測る(無料・匿名)
  3. 方法3〜4：人に聞いて測る(精度が高い)
  4. 方法5：ギャップから測る(行動に直結する)
  5. 結果の読み方と、測る習慣

測定の前に：何を測るのかを整理する

測定を始める前に、市場価値の構造を踏まえて、測るべき対象を整理します。市場価値は単一の数字ではなく、複数の側面を持ちます。

測る対象何が分かるか測定の難易度
提示される年収の水準自分の経験に対する金銭的な評価比較的容易
声がかかる頻度と質市場からの需要の強さ容易(受動的に分かる)
応募が通る確率書類・面接での競争力実際に応募すれば分かる
選べる求人の幅選択肢の広さ。業界・職種をまたげるか求人検索で確認可能
求められる要件との適合市場が求めるものと自分の持ち物のギャップ求人票の分析で分かる

多くの人は1番目(年収)だけを気にしますが、実務的に重要なのは4番目の「選択肢の幅」です。同じ年収でも、選べる会社が10社ある人と1社しかない人では、市場での立場がまったく違います。そして、この幅こそが、いざというときの安全性と交渉力を決めます。

また、5番目の「要件とのギャップ」は、測定の中で最も行動につながる情報です。市場が求めているのに自分が持っていないものが分かれば、次に何を身につけるべきかが明確になります。測定の目的は、点数をつけることではなく、次の行動を決めることにあります。

方法1〜2：求人情報から測る(無料・匿名)

最も手軽で、誰にも知られずにできる方法から始めます。

方法1：求人の相場を調べる。転職サイトで、自分の職種・経験年数・地域の条件で検索し、提示されている年収レンジを確認します。ポイントは、

  • 複数のサイトで確認する — サイトによって掲載企業の傾向が違うため、1つでは偏る
  • 求人票の「必須要件」と自分を照合する — 満たしている求人の年収レンジが、現実的な相場
  • 上位レンジの求人の要件を見る — 高い年収の求人が何を求めているかは、次に身につけるべきものを示す
  • 掲載年収と実際の提示額は違うことを理解する — 「400〜800万円」の求人で、自分がどこに位置するかは経験次第

この作業を1時間行うだけで、自分の相場感は大きく変わります。多くの人は、自分の市場価値を過小評価しているか、あるいは実態とずれた期待を持っています。事実に触れることが、第一歩です。

方法2：スカウトサービスに登録して反応を見る。職務経歴を登録し、届くスカウトの量と質を観察します。これは需要の強さを測る、最も直接的な方法です。

観察すべきは、(1)スカウトの件数、(2)提示されている年収レンジ、(3)企業の種類(業界・規模)、(4)一斉送信ではなく、経歴を読んだ上での個別メッセージがどれだけあるか。特に4番目が重要で、個別性の高いスカウトが来るかどうかが、市場からの本当の関心の指標です。

注意点として、現職に知られたくない場合は、企業ブロック設定(自社と関連会社を非公開にする機能)を必ず行ってください。多くのサービスに機能があります。

方法3〜4：人に聞いて測る(精度が高い)

求人情報からの推測より精度が高いのが、市場を知る人に直接聞く方法です。

方法3：転職エージェントに相談する。転職の意思が固まっていなくても、面談は可能です。「情報収集の段階」と伝えた上で、次の質問をしてください。

  1. 「私の経歴だと、市場ではどのくらいの年収レンジになりますか」
  2. 「どんな業界・職種の求人が該当しますか」——選択肢の幅が分かる
  3. 「私の経歴で、評価される点と、弱いと見られる点は何ですか」——最も価値ある情報
  4. 「この年収を上げるには、どんな経験が必要ですか」——次の行動が見える

特に3番目と4番目が、エージェント面談の最大の収穫です。市場のプロが、あなたの経歴を客観的に評価した情報は、自己認識の補正に極めて有用です。無料で得られる情報としては、質が突出しています。

ただし、エージェントのビジネスモデルを理解した上で受け取ってください。転職を促す方向のバイアスがあり得ること、また扱う求人領域によって見える市場が偏ることを踏まえ、複数社の意見を聞くのが賢明です。2〜3社に会えば、共通する評価が見えてきます。

方法4：実際に応募して選考を受ける。最も精度が高い測定方法です。書類が通るか、面接でどう評価されるか、いくらの提示が出るか——すべてが事実として返ってきます。

転職の意思が固まっていない段階での応募には、ためらいがあるかもしれません。しかし、選考を受けることは転職の約束ではなく、内定を辞退する自由は常にあります。年に1社でも選考を受ける習慣は、自分の市場価値を最も正確に知る方法であり、また面接の練習にもなります。

方法5：ギャップから測る(行動に直結する)

最後は、数字ではなく要件との差分を測る方法です。行動につながる情報が最も多く得られます。

手順は次の通りです。

ステップ1：自分が「行きたい」と思える求人を10件集める。年収、仕事内容、企業の規模など、条件が魅力的なもの。現時点で応募できるかどうかは考えず、目指したい水準で選びます。

ステップ2：それぞれの「必須要件」「歓迎要件」を書き出し、共通項を抽出する。10件の求人が共通して求めているものが、その市場での標準的な期待です。

ステップ3：自分が満たしているもの・いないものを分類する。満たしていないものが、市場価値を上げるために埋めるべきギャップです。

ステップ4：ギャップを「いまの環境で埋められるもの」と「環境を変えないと埋められないもの」に分ける。前者は現職での行動計画に、後者は転職や異動の判断材料になります。

この作業の価値は、抽象的な「市場価値を上げたい」を、具体的な行動に変えることです。「マネジメント経験が必要」なら、いまの環境で小さくてもチームを持つ機会を取りにいく。「特定の業界知識」なら、その勉強を始める。「英語」なら、必要な水準を確認して学習計画を立てる。

この方法は、転職を前提としない人にとっても有効です。目指す求人が求める要件は、その職種の市場での標準です。それを知っておくだけで、いまの環境での仕事の選び方、手を挙げる機会の選び方が変わります。

結果の読み方と、測る習慣

測定結果を、どう解釈し、どう活用するか。最後に整理します。

読み方1：単一の情報で判断しない。1社のエージェントの評価、1回のスカウトの年収提示は、サンプルとしては小さすぎます。複数の情報源(求人相場、複数エージェント、スカウトの傾向)が同じ方向を示すなら、それは信頼できる情報です。

読み方2：低い結果に落ち込まない、高い結果に慢心しない。低い場合、原因は(1)言語化ができていない、(2)測っている市場がずれている、(3)実際に経験が不足している、のいずれかです。それぞれ対処法が違います。高い場合も、それは現在の需給の結果であり、陳腐化のリスクは常にあります。

読み方3：年収より選択肢の幅を見る。前述の通り、実質的な市場価値は選択肢の広さに現れます。「年収は横ばいだが、選べる業界が増えた」なら、それは市場価値の向上です。

測る習慣としては、年1回の定点観測を勧めます。具体的には、

  1. 年1回、職務経歴書を更新する — 直近1年の担当と成果を追記する。これ自体が経験の言語化の訓練になる
  2. 年1回、エージェント1〜2社と面談する — 市場の変化と、自分の評価の変化を確認する
  3. 四半期に一度、求人相場を眺める — 自分の職種の求人がどう変化しているか(要件、年収、募集企業)を10分見る
  4. スカウトの傾向を観察する — 登録したままにしておけば、受動的に情報が入る

この習慣の効用は、転職の準備にとどまりません。自分の現在地を知っている状態は、いまの職場での交渉力にもなり、環境が急変したときの対応力にもなります。そして何より、漠然とした不安——「自分は市場で通用するのだろうか」——を、事実で解消できます。

市場価値の測定は、転職を決めた人がする特別な作業ではなく、キャリアの定期健診です。年1回、数時間。この投資が、判断の質と心の余裕の両方をもたらします。

よくある質問

転職する気がないのにエージェントに会うのは、失礼ではないですか?

失礼ではありません。エージェントは中長期の関係を重視しており、「今すぐではないが、いずれ動く可能性のある人」との接点を持つことは、彼らのビジネスとしても合理的です。ただし、誠実な伝え方はしてください——「現時点で転職を決めているわけではなく、市場を知りたい段階です」と最初に明言する。この前提を共有すれば、双方にとって無駄のない面談になります。逆に、転職意思があるふりをして情報だけ得ようとするのは、信頼を損ないます。正直に伝えることが、良い関係の出発点です。

市場価値診断ツールの結果は信用できますか?

参考程度に留めてください。ツールは入力された属性(年齢・職種・年収・スキル)から統計的な推定を行うもので、あなた固有の経験の質は反映されません。また、サービスによっては転職を促す方向の演出が含まれることもあります。有用な使い方は、(1)おおまかな相場感を掴む入口として使う、(2)結果の数字ではなく、「どんな要素が評価されるのか」という項目の構成を参考にする。本記事の方法1〜5の方が、手間はかかりますが、はるかに実態に近い情報が得られます。

スカウトがたくさん来ますが、これは市場価値が高いということですか?

量だけでは判断できません。確認すべきは質です。(1)一斉送信か、経歴を読んだ個別メッセージか——多くのスカウトは条件検索での一斉配信です、(2)提示年収は現職より高いか、(3)自分が行きたいと思える企業からか。件数が多くても、内容が定型文で、年収も現状維持レベルなら、それは「その属性の人材を広く探している市場がある」という以上の意味は持ちません。逆に、経歴の具体的な部分に言及した個別スカウトが数件来る方が、市場価値の指標としては強い情報です。

測った結果、いまの年収の方が市場より高いと分かりました。どう考えるべきですか?

重要な情報です。考えられる背景は、(1)現職での評価が高い(社内での実績・関係が評価されている)、(2)勤続による積み上げ(年功的な要素)、(3)業界・企業の水準が高い、のいずれかです。この状態の含意は2つ。第一に、いま転職すると年収は下がる可能性が高い——転職の判断では、年収以外の価値との比較が必要です。第二に、**その待遇は現職に依存している**——会社の状況が変われば失われる可能性があります。したがって、現職を大切にしつつ、[市場でも通用する経験](/column/portable-skill/)を積むことが、リスク管理として重要になります。

測定のために面接を受けて、内定を辞退するのは相手に迷惑では?

選考は相互の見極めの場であり、辞退は候補者の正当な権利です。企業も、辞退を織り込んで採用活動を行っています。ただし、最低限の礼儀は守ってください——(1)明らかに応募する気のない企業に、練習目的だけで応募しない、(2)辞退は決まり次第、速やかに丁寧に伝える、(3)選考中は誠実に対応する。この3点を守れば、問題はありません。むしろ、選考を通じて相互理解が深まった結果として「今回は縁がなかった」となるのは、選考の正常な機能です。

この記事のまとめ

  • 測るべきは年収だけでなく、声のかかり方・通過率・選択肢の幅・要件とのギャップ。特に幅とギャップが重要
  • 方法1〜2は求人相場の確認とスカウト登録。無料・匿名で、企業ブロック設定をすれば現職に知られない
  • 方法3〜4は人に聞く方法。エージェント面談では「評価される点・弱い点・上げるには何が必要か」を聞く
  • 方法5は行きたい求人10件の要件から自分のギャップを抽出する。抽象的な向上心を具体的な行動に変える
  • 読み方は、単一情報で判断しない・低さに落ち込まず高さに慢心しない・年収より選択肢の幅を見る
  • 年1回の経歴書更新とエージェント面談を定点観測に。市場価値の測定はキャリアの定期健診
