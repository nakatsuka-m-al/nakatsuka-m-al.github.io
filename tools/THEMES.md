# コラム テーマ設計（全160本 / 各セグメント40本）

## 設計方針

コーポレートサイトへの流入は**指名検索が中心**（「中塚正勝」「blaze 中塚」等）。
つまり読者は**すでにBLAZEを知っている人**＝商談前の決裁者・提携候補・採用候補者。

したがってこのコラムの役割は「検索から人を連れてくる装置」ではなく、
**「この会社は分かっているか」を確認される材料**である。

### Oubo Payコラム（231本）との棲み分け

| | Oubo Pay | コーポレート |
|---|---|---|
| 読者 | 検索で来た採用担当者 | 商談前に調べている決裁者 |
| 型 | 網羅・比較・手順（HOW） | 論考・構造・経営視点（WHY / WHAT） |
| 既存 | 媒体ガイド133本、業種別、派遣実務13本 | — |
| 本コラムで書かない | — | 媒体名・業種別・派遣実務 |

### 実データに基づく方針

Search Console（3ヶ月）より:

- 他社サービス名クエリ（「インディードプラス 料金」91表示）→ **CTR 0%**
- 課題・構造クエリ（「採用 予算 立て方」16表示）→ **CTR 12.5%**

→ **他社名を狙わない。課題・構造クエリを狙う。**
